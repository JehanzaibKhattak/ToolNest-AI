# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature on this repository and include affected routes, reproduction steps, impact, and any suggested mitigation.

Do not include real API keys, access tokens, resumes, emails, PDFs, or other personal data in a report. Credentials exposed during testing should be revoked immediately.

## Supported version

Security fixes are applied to the latest version on the default branch. This project is an early-stage MVP and has not received an independent security audit.

## Deployment responsibility

Operators are responsible for configuring Supabase Row Level Security, secret environment variables, retention policies, abuse controls, and appropriate privacy terms before handling production user data.
